# CloudTrail

Creates a CloudTrail audit logging baseline for TITAN.

## Purpose

- Capture account activity
- Support audit evidence
- Feed GuardDuty threat detection
- Support compliance monitoring
- Enable multi-region visibility

## Resources

- S3 bucket for CloudTrail logs
- S3 bucket public access block
- S3 bucket policy
- Multi-region CloudTrail
- Log file validation
- Management event logging
- Optional KMS encryption
