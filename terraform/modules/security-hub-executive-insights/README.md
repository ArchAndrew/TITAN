# Security Hub Executive Insights

Creates executive-focused AWS Security Hub Insights for TITAN.

## Purpose

Transforms raw Security Hub findings into leadership-friendly views focused on governance, risk, and compliance.

## Insights

- TITAN Public Exposure Findings
- TITAN IAM Risk Findings
- TITAN Failed Compliance Findings
- TITAN Encryption Findings

## Value

These insights help security and platform teams quickly answer:

- Where are externally exposed resources?
- Which IAM-related risks need attention?
- Which compliance controls are failing?
- Which resources have encryption-related findings?

## Dependencies

Security Hub must already be enabled.

Recommended dependencies:

- AWS Config
- AWS Config Rules
- Security Hub Standards
- GuardDuty
- CloudTrail
- KMS
