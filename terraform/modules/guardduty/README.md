# GuardDuty

Enables AWS GuardDuty threat detection.

## Features

- GuardDuty Detector
- S3 Protection
- EKS Audit Log Monitoring

## Purpose

Provides managed threat detection across:

- AWS Accounts
- S3 Buckets
- Kubernetes (EKS)
- IAM Activity
- CloudTrail Events

## Integration

GuardDuty findings flow into Security Hub for centralized visibility.
