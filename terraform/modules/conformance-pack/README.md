# Conformance Pack

Creates an AWS Config Conformance Pack for the TITAN security baseline.

## Purpose

Groups AWS Config managed rules into a reusable governance baseline.

## Controls

- S3 public read prohibited
- S3 public write prohibited
- Encrypted EBS volumes
- Root account MFA enabled
- CloudTrail enabled
- IAM password policy

## Value

This turns individual Config Rules into a governance framework that can detect configuration drift and support compliance reporting.
