# EventBridge Security Hub Actions

Routes Security Hub custom action events into a CloudWatch log group.

## Purpose

This module captures analyst-driven Security Hub custom action events generated by TITAN action targets.

## Architecture

Security Hub Finding  
→ TITAN Custom Action  
→ EventBridge Rule  
→ CloudWatch Logs  

## Use Cases

- Validate custom action event flow
- Capture investigation/escalation/suppression events
- Prepare for Lambda or Step Functions response workflows
