# Security Hub Automation Rules

Creates AWS Security Hub automation rules for TITAN security operations triage.

## Purpose

Automation rules classify and enrich Security Hub findings so security teams can prioritize response activity.

## Rules

- TITAN Critical Findings Triage
- TITAN IAM Risk Findings Triage
- TITAN S3 Public Exposure Triage

## Value

This module extends TITAN from visibility into action by automatically classifying findings with priority, category, and routing metadata.

## Dependencies

Security Hub must already be enabled.
