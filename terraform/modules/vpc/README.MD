# TITAN VPC

Dedicated VPC foundation for TITAN platform workloads.

## Includes

- VPC
- 3 public subnets
- 3 private subnets
- Internet Gateway
- NAT Gateway
- Public and private route tables
- EKS-compatible subnet tags

## Purpose

Provides a dedicated network foundation for EKS and platform workloads instead of relying on the AWS default VPC.
